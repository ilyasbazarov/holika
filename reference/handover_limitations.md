# Реестр известных ограничений (ADR-156 §2)

- Диагностические сообщения загрузчика продаж не доходят до журнала облака: сообщения уровня
  INFO функции cf-facts в Cloud Logging не появляются ни в одном из проверенных окон
  (сессии FACTS-BACKFILL 2026-08-08, SALES-REFRESH-WINDOW-DEPLOY-FINAL 2026-08-12). Отказы
  видны — они приходят текстом ошибки в исполнение конвейера; невидима только штатная
  диагностика. Причина не расследовалась.
- Бывают сутки почти без продаж (2026-08-11 — два документа на 111 738,60 сом). Проверка
  качества считает такие сутки подозрительными и придерживает обновление витрин до смены
  суток; данные при этом верны и совпадают с МойСклад до копейки. Форма проверки, снимающая
  этот случай, спроектирована, но не выложена.
- Состояние функции в облаке читается двумя разными способами, и они расходятся: описание
  функции отдаёт последнюю собранную версию, а обслуживать запросы может другая. Сверять
  обязательно с тем, на что переведён трафик.
- Витрина `marts.weight_flow` читается страницей «Склад» напрямую, без промежуточного запроса.
  Источник данных Looker Studio перечисляет поля закрытым поимённым списком (восемь измерений,
  совпадающих со схемой таблицы один в один, снято владельцем 2026-08-18), поэтому две колонки
  отметки времени сборки, добавленные в тот же день, в интерфейсе потребителя не появляются, пока
  кто-нибудь не обновит список полей источника вручную. Ничего не ломается — все элементы страницы
  адресуют поля по имени. Если отметка времени понадобится на самой странице, список полей
  источника нужно обновить в интерфейсе.
- В источнике данных Looker Studio у поля `weight_coverage_pct` (доля позиций с заполненным весом,
  проценты) стоит агрегирование по умолчанию «Сумма». Сумма долей величины не имеет: две строки по
  60 % дадут 120 %. Поле считается построчно в запросе витрины; корректная агрегация — среднее,
  точнее — взвешенное (`SUM(positions_with_weight)/SUM(positions_total)`). Дефект предшествует
  отметке времени сборки и ею не создан. Проверка, использует ли этот показатель хоть один элемент
  страницы «Склад», требует интерфейса и на дату передачи не выполнялась.
- У витрины `core.dim_fx_rates` отметки времени сборки нет и не будет: исходников функции `cf-fx`,
  которая её строит, нет ни в репозитории проекта, ни в репозитории кода — форма правки не
  спроектирована. Замершая таблица курсов внешне неотличима от живой; проверять её свежесть надо
  вручную, сравнивая максимальную дату курса с сегодняшней. Выведено из объёма работ решением
  владельца 2026-08-10 (`reference/scope_close_freeze_2026-08-10.md §5`).
- У витрины `marts.expenses_staging` отметки времени сборки нет и не будет: ни один живой
  Custom Query или Cloud Function, строящий эту таблицу, не найден — проверены спецификация
  пайплайна, инвентарь конфигураций переноса и снимки SQL, ноль совпадений. Адрес строителя лежит
  вне репозитория и не установлен, форма правки не спроектирована. Та же оговорка про ручную
  проверку свежести, что у таблицы курсов. Выведено из объёма работ решением владельца 2026-08-10
  (`reference/scope_close_freeze_2026-08-10.md §5`).
- Блокирующее действие DQ Gate не снимается автоматически ни по времени, ни кнопкой подтверждения
  — оператор обязан разобрать причину и снять блок вручную (после суток непрерывной блокировки —
  обязательно, не по желанию). Это сознательный выбор, а не недоделка: автоматическое снятие было
  бы формой того же дефекта, который уже закрывался отдельно (тихий пропуск данных, которые сами
  были причиной остановки), а кнопка «пропустить» технически означает прямой вызов ядра в обход
  проверки, у которого есть собственная опасность при неверных параметрах. Процедура ручного
  снятия и диагностический запрос — `reference/dq_gate_block_bounded_2026-08-17.md`.
- Тридцать четыре платежа 2024 года ссылаются на валюту, которой нет в справочнике валют
  МойСклада, и не несут курса документа. Их суммы посчитаны по курсу 1.0 (существующая
  запасная ветка загрузчика), то есть верны только если эта валюта — сом. Найдено первым же
  прогоном новой проверки валют 2026-08-18; двадцать два опознанных документа лежат в
  2024-06-18…2024-09-17 на 378 517,09 сом. Окна паритета (с 2026-05-01) это не касается —
  цифры, которые сверяются с интерфейсом МойСклад, затронуты не могут быть по датам.
  Установить, что это за валюта, можно одним чтением справочника МойСклада.
