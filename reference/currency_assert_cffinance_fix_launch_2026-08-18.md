## 1. Поправка к форме правки: «три строки» назвали не тот механизм

Вердикт ревью (§«Что делать дальше») предписывал три строки: `timeout=90`,
`resp.raise_for_status()`, `(resp_json.get("meta") or {})`. **Средняя строка в таком виде создаёт
новый путь отказа вместо того, чтобы его закрыть**, и это выяснилось при подготовке правки:

`raise_for_status()` без ретрая превращает ЛЮБОЙ временный `429`/`5xx` справочника валют в
падение всей суточной загрузки платежей. То есть диагностика, добавленная ради наблюдаемости,
получала бы право ронять то, что она наблюдает. Это ровно тот класс размена, который проект уже
разбирал на DQ Gate (`ADR-152`): механизм наблюдения не должен быть строже наблюдаемого процесса.

**Различитель найден в том же деплойном объекте.** `invoices.py` (задеплоен 2026-08-03 в эту же
функцию) несёт `_api_get` с `tenacity`: `429` и `5xx` ретраятся экспоненциально до пяти попыток,
`401` падает сразу. `requirements.txt` уже содержит `tenacity`. То есть в `cf-finance` доступны
три уровня зрелости, и выбирать надо осознанно:

| Вариант | Что даёт | Чем платим |
|---|---|---|
| (A) только `timeout` + `raise_for_status` | явный отказ вместо тихого | **временный `429` роняет суточную загрузку платежей** — отвергнут |
| **(B) строгий внутри, терпимый снаружи** | недоступность справочника гасит ТОЛЬКО диагностику, загрузка идёт; ложных срабатываний нет; «не выполнялась» отличимо от «ноль несовпадений» | диагностика может пропустить прогон — но об этом печатается предупреждение |
| (C) переиспользовать `invoices._api_get` с ретраями | плюс к (B) — переживает временные отказы | межмодульная связь с приватной функцией, объём деплоя и его ревью растут |

**Принято (B).** (C) остаётся кандидатом на потом с названным триггером: если предупреждение
«карта валют недоступна» появится в журнале дважды за месяц — переходим на ретраи.

## 2. Точная форма правки (объём — только `reference/code/cf-finance/main.py`)

**(i) Внутри `_fetch_currency_map` — строго:**

```python
        resp = requests.get(url, headers=headers, timeout=90)   # 02_ERP_CONTRACTS §поведение API
        time.sleep(0.25)
        resp.raise_for_status()
        resp_json = resp.json()
        for row in resp_json.get("rows", []):
            currency_map[parse_href(row)] = row.get("isoCode")
        url = (resp_json.get("meta") or {}).get("nextHref")     # канон ADR-171 §6 для нового кода
```

**(ii) На месте вызова в `run_etl()` — терпимо:**

```python
    # INGEST-CURRENCY-ASSERT Шаг 3: карта валют для детекции ниже. Диагностика не имеет права
    # ронять загрузку, которую наблюдает: недоступность справочника гасит детекцию, не ETL.
    try:
        currency_map = _fetch_currency_map(token)
    except Exception as e:
        currency_map = None
        print(f"WARNING: карта валют недоступна ({type(e).__name__}: {e}) — "
              f"детекция INGEST-CURRENCY-ASSERT в этом прогоне НЕ выполнялась")
    currency_mismatch = 0
```

**(iii) Детекция исполняется только при живой карте** — иначе `iso_code` был бы `None` у каждой
строки и проверка дала бы ложное срабатывание на всех платежах:

```python
                if currency_map is not None:
                    rate_obj    = row.get("rate") or {}
                    has_rate    = rate_obj.get("value") is not None
                    currency_id = parse_href(rate_obj.get("currency"))
                    iso_code    = currency_map.get(currency_id) if currency_id else None
                    if not (iso_code == "KGS" or has_rate):
                        currency_mismatch += 1
                        print(...)          # существующий текст предупреждения не меняется
```

**(iv) Итоговая печать различает три состояния** — иначе «детекция не работала» читалось бы как
«несовпадений нет», а это и есть тихий пропуск:

```python
    if currency_map is None:
        print("WARNING: детекция INGEST-CURRENCY-ASSERT в этом прогоне НЕ выполнялась "
              "(карта валют недоступна)")
    elif currency_mismatch:
        print(f"WARNING: {currency_mismatch} платежей с валютой ≠ KGS без rate.value "
              f"(currency_mismatch, INGEST-CURRENCY-ASSERT)")
```

**Запрещено (расширение объёма молча стоило проекту отката — `ADR-161`):** трогать
`main.py:66` и любой другой существующий запрос (ретрофит, `ADR-171 §6` его не требует); трогать
строку расчёта суммы (`main.py:105`) и находку `ADR-029 §1` в ней; трогать `invoices.py`,
`requirements.txt`, `trigger_marts()`, диспетчер `main()`; что-либо деплоить.
