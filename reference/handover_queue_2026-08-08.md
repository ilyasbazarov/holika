# /reference/handover_queue_2026-08-08.md — очередь до передачи проекта клиенту

**Задача:** `HANDOVER-QUEUE-ADJ` (второй ход сессии `SALES-JULY-K-DISCRIMINATE-ADJ`, архитектор,
класс A, без брифа — `ADR-086 §1`; строка задачи заведена собственным блоком, `ADR-086 §3`,
прецедент `FINISH-CALIBRATION`/`ADR-125`).

**Что это.** Сплошной проход по всем открытым строкам `07_STATE.md §Открытые вопросы` (индекс на
`2026-08-08`, SHA базы `5dab461`) с квалификацией каждой строки по критерию отсечения фазы
передачи (`ADR-140 §4`): задача входит в передачу, только если её невыполнение даёт
**(i)** неверное число либо подпись на клиентской поверхности, **(ii)** тихий отказ, либо
**(iii)** неремонтопригодность без нас.

**Что это НЕ.** Не новая постановка задач и не переоценка статусов. Статус, гейт и класс каждой
строки взяты из реестра дословно; здесь добавлены только квалификация по `ADR-140 §4`, порядок и
факт наличия брифа. Ни одна строка этим артефактом не переводится в другой статус.

**Метод проверки наличия брифа:** `ls briefs/` на `5dab461`, сопоставление по имени файла
`briefs/<TASK>.md`. Отсутствие файла печатается как «нет», не как «не нужен» — необходимость брифа
квалифицирована отдельно по `ADR-086 §1` (класс A с дословной приёмкой в реестре брифа не требует).

## Что в передачу НЕ входит и почему

Ни одна из строк ниже не даёт клиенту неверного числа, тихого отказа и не делает систему
неремонтопригодной — критерий `ADR-140 §4` не выполняется.

- **Внутренний метод и инструменты сессий:** `CC-READONLY-PRINCIPAL`, `METHOD-PROMOTE-LOCAL-RULES`,

  `GATE-STATE-VERIFIABILITY`, `Q-102`, `BQ-QUERY-MAX-ROWS`, `Q-40`, `Q-84`, `Q-85`, `Q-94`,
  `Q-62`, `Q-68`, `Q-75`, `Q-76`.
- **Отложенные с названными триггерами:** `Q-7` (TTL токена банка), `Q-9`, `Q-28`, `Q-30`, `Q-34`,
  `Q-35`, `Q-37`, `Q-38`, `Q-47`, `Q-69`, `Q-70`, `Q-101`, `Q-104`, `Q-105`, `RQ-3`,
  `SALES-PERIMETER-CHANNEL-REAL`, `INTRANSIT-CADENCE-COST-PROBE`,
  `SALES-EMPLOYEE-ATTRIBUTION-MAY-SUM-GAP`, `Q-20` (работа перенесена в `INGEST-CURRENCY-ASSERT`),
  `Q-3` (место хранения кода фактически выбрано `ADR-109 §5`, строка отстала от факта).
- **Не отдаётся инструменту, исполняет владелец:** `MSKLAD-TZ-PROPOSAL`, `Q-92` (ждёт ответа
  клиента по часовому поясу), `PARITY-ZONE-SNAPSHOT-DECISION`.
- **Заблокировано входом владельца:** `E1-T2-MECH-TAX` — нужны число начисления налогов и
  каденс; без них не двигается ни в каком классе.

## Рекомендация к немедленному запуску (выбор за владельцем)

Три задачи, не конфликтующие между собой:

1. **№13 `SALES-JULY-K2K3-DISCRIMINATE`** — мандат выдан, приёмка написана, запускается сегодня.

   единственный жёсткий срок в очереди (`2026-09-29`).

(`bash tools/parallel_check.sh <TASK1> <TASK2>`, `ADR-082 §1`/`ADR-102`); №2 и №1 — класс B и не
параллелятся ни с чем по построению.
