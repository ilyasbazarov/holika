## NEW_DECISIONS

- ADR-0XX: Выезд `cf-dq` принят по всем пяти пунктам и строка `2` списка закрытия закрыта;
  ревью шага (2) приземлено с собственным замером; мандаты строки `7` выданы на два объекта из
  трёх, третий держится предметным гэпом; механизм `b1` различителя `29` строк опровергнут

  **Контекст.** Цепочка из семи ног довела остаток строки `2` до конца: правка порядка `CHECKS`,
  повторное ревью, деплой по заново выданному мандату, приёмка. Ревью шага (2) было выдано в
  чате и в репозитории не приземлено. Одновременно владелец поручил разобрать, что блокирует
  выдачу мандатов строки `7`, и заняться остатком различителя `29` удалённых строк.

  **Решение.**
  **§1 Приёмка выезда `cf-dq` принята целиком.** Пять пунктов
  `dq_freshness_wire_deploy_review_2026-08-17.md §5` закрыты фактами, включая обязательный
  третий: состав живого механизма предъявлен записью `audit.dq_runs` первого ЕСТЕСТВЕННОГО
  часового прогона (`19` проверок, все двенадцать `freshness_*` поимённо, ни одной
  `passed=false`). Строка `2` списка закрытия закрыта целиком, счётчик `7` → `6` из `9`.
  **§2 Ревью шага (2) приземлено с собственным замером архитектора,** не пересказом отчёта:
  обход `ast` по узлам верхнего уровня дал `0` форвард-ссылок, дифф после фильтрации строк
  перенесённого блока пуст. Замер `ast` объявляется формой, ПРЕВОСХОДЯЩЕЙ импорт для этого
  класса дефекта: импорт останавливается на первой ошибке, обход разрешает имена по всему модулю.
  **§3 База ветки по `ADR-190` применена с первого захода** — прод-коммит найден сверкой
  `sha256`, оба инварианта `is-ancestor` истинны. Правило работает и остановок больше не стоило.
  **§4 Отклонение адреса артефакта названо и переисполнения не требует:** разбор деплоя ушёл в
  `MANIFEST.md` вместо `reference/dq_freshness_wire_deploy_<date>.md`; провенанс полон.
  **§5 Мандаты строки `7`: два выданы, один держится.** Условная выдача владельца («нет
  критических возражений — выдавай») разрешена пообъектно, поскольку пакетная выдача запрещена
  (`ADR-115 §5`): возражений нет по `sq_marts_customer_invoices_ar` и `sq_marts_expenses`
  (потребители перечисляют колонки явным списком, правка аддитивна, откат лежит в репо), есть по

  снимается ответом владельца, а не суждением архитектора.
