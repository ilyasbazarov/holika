## NEW_DECISIONS

- ADR-0XX: Выезд `cf-dq` принят по всем пяти пунктам и строка `2` списка закрытия закрыта;
  ревью шага (2) приземлено с собственным замером; мандаты строки `7` выданы на два объекта из
  трёх, третий держится предметным гэпом; механизм `b1` различителя `29` строк опровергнут

  **Контекст.** Цепочка из семи ног довела остаток строки `2` до конца: правка порядка `CHECKS`,
  повторное ревью, деплой по заново выданному мандату, приёмка. Ревью шага (2) было выдано в
  чате и в репозитории не приземлено. Одновременно владелец поручил разобрать, что блокирует
  выдачу мандатов строки `7`, и заняться остатком различителя `29` удалённых строк.

  **Решение.**
  **§1 Приёмка выезда `cf-dq` принята целиком.** Пять пунктов
  `dq_freshness_wire_deploy_review_2026-08-17.md §5` закрыты фактами, включая обязательный
  третий: состав живого механизма предъявлен записью `audit.dq_runs` первого ЕСТЕСТВЕННОГО
  часового прогона (`19` проверок, все двенадцать `freshness_*` поимённо, ни одной
  `passed=false`). Строка `2` списка закрытия закрыта целиком, счётчик `7` → `6` из `9`.
  **§2 Ревью шага (2) приземлено с собственным замером архитектора,** не пересказом отчёта:
  обход `ast` по узлам верхнего уровня дал `0` форвард-ссылок, дифф после фильтрации строк
  перенесённого блока пуст. Замер `ast` объявляется формой, ПРЕВОСХОДЯЩЕЙ импорт для этого
  класса дефекта: импорт останавливается на первой ошибке, обход разрешает имена по всему модулю.
  **§3 База ветки по `ADR-190` применена с первого захода** — прод-коммит найден сверкой
  `sha256`, оба инварианта `is-ancestor` истинны. Правило работает и остановок больше не стоило.
  **§4 Отклонение адреса артефакта названо и переисполнения не требует:** разбор деплоя ушёл в
  `MANIFEST.md` вместо `reference/dq_freshness_wire_deploy_<date>.md`; провенанс полон.
  **§5 Мандаты строки `7`: два выданы, один держится.** Условная выдача владельца («нет
  критических возражений — выдавай») разрешена пообъектно, поскольку пакетная выдача запрещена
  (`ADR-115 §5`): возражений нет по `sq_marts_customer_invoices_ar` и `sq_marts_expenses`
  (потребители перечисляют колонки явным списком, правка аддитивна, откат лежит в репо), есть по
  `sq_marts_weight_flow` — страница «Склад» подключена к таблице НАПРЯМУЮ, состав полей задаётся
  конфигурацией Looker Studio, которой в репозитории нет. Гэп предметный, а не формальный, и
  снимается ответом владельца, а не суждением архитектора.
  **§6 Приёмка применения отметки получает третий пункт по образцу `Q-111`:** предъявляется
  состав живого результата (обе колонки не пусты в целевой таблице), а не факт подмены текста
  конфигурации. Прямой перенос урока выезда `cf-dq`, где приёмка по файлу прошла, а цель
  достигнута не была.
  **§7 Механизм `b1` гипотезы (b) различителя `29` строк опровергнут замером:** в архиве сырого
  ответа источника есть документ со `104` позициями и ноль документов на границе `100` — обрезки
  позиций постраничным пределом не существует. Гипотеза (b) целиком не опровергнута; строка
  остаётся `PARTIAL`. Снятый критерий `ADR-165` не воскрешался, замер бьёт по механизму, а не
  повторяет метку.

  **§8 Гэп `weight_flow` закрыт входом владельца, третий мандат выдан.** Список полей источника
  Looker Studio (восемь измерений плюс `Record Count`) совпал со схемой `marts.weight_flow`
  один в один — источник адресует поля поимённо, позиционного доступа и режима «все поля» нет,
  следовательно две добавляемые колонки не способны сдвинуть, переименовать или скрыть ни одно из
  восьми. Прецедент опасности (`msklad_inventory_latest`) сюда не переносится: там риск создаёт
  `SELECT *`, здесь список закрыт и предъявлен. Отдельно зафиксировано: финальная склейка живого
  запроса позиционна (`UNION ALL` двух `SELECT *`), поэтому подготовленный текст применяется как
  есть и не пересобирается исполнителем; доказательство корректности — пройденный `--dry_run`,
  проверяющий арность `UNION ALL`.
  **§9 Настройки графика Топ-20 исключены как класс причин.** Ни источник, ни параметр по имени
  товара, ни показатель, ни параметр диапазона дат, ни DERIVED-показатель в USD не способны
  породить `27 835,21` KGS на одном товаре; собственного периода у элемента нет. Вместе с ранее
  измеренными слоями не остаётся слоя, где расхождение могло бы родиться, кроме момента чтения —
  что установлено фактом `ADR-177 §1`. Остаток строки `4` сводится к подтверждающему чтению
  владельца, а не к новому замеру.
  **§10 Мандат класса B на ступень 3 различителя выдан** (владелец, чат `2026-08-18`): единицы
  read-only `GET` к `api.moysklad.ru` по паре маркетплейса. Вопрос поставлен бинарно, вердикт по
  остальным `10` строкам этим чтением не выносится и переносом не распространяется (`ADR-165`).
  **§11 Наблюдение по данным владельца:** `weight_coverage_pct` в источнике Looker Studio
  агрегируется суммой, а это доля в процентах — сумма долей по строкам величины не имеет. Дефект
  предшествует нашей правке и ею не создаётся; строку реестра не заводит (`ADR-156 §2/§5`), уходит
  текстом в реестр известных ограничений.
