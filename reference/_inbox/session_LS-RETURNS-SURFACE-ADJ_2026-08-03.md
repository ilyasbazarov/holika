## NEW_DECISIONS

- ADR-0XX: Поверхностью BI пары реестра паритета является ГРАФИК, а не источник данных; пара
  «Возвраты покупателей» сошлась и переназначена на Executive summary
  Контекст: реестр паритета называл поверхностью пары возвратов Custom Query
  `msklad_counterparty_returns`. Единственный график на этом источнике («Топ контрагентов»,
  «Операционка») выводит Контрагента, Страну, Выручку, Маржу и % от общего дохода — ни одной из трёх
  колонок возвратов. Состав полей графиков инвентарь `reference/ls_custom_queries_2026-07-30.md`
  снимал только для одного источника из пяти. Пять суток пара числилась несошедшейся по признаку,
  который никто не проверял, при том что численное совпадение `570,00` = `570,00` было установлено
  ещё 2026-08-01 тремя независимыми путями.
  Решение: (§1) поверхностью BI пары реестра является выведенный на дашборд ГРАФИК с конкретным
  составом полей, а не Custom Query и не таблица-основа; величина, которую ничто не рисует,
  сверяемой поверхностью не является; (§2) пара «Возвраты покупателей» переназначается на блок
  возвратов Executive summary (источник `fact_returns`), уровень — итог за период дашборда, и
  объявляется СОШЕДШЕЙСЯ по read-back владельца `570` за май-2026; счётчик реестра 1/7 → 2/7;
  (§3) разрез возвратов по контрагенту остаётся ВНЕ финишной черты до появления рисующего его
  графика; расширение реестра — решение владельца, предложение сделано и ОТКЛОНЕНО (чат 2026-08-03),
  вопрос закрыт; (§4) при работе с любой парой реестра состав полей её графика снимается явно и
  фиксируется в артефакте — «источник подключён» не есть «величина видна».
