  **Дата:** 2026-07-29 · **Статус:** §1–§8 accepted. §1–§4, §6, §7 — архитектор; §5 (перенос деревьев)
  и §8 (архитектор внутри инструмента) — accepted ВЛАДЕЛЬЦЕМ 2026-07-29 в ответ на развилки, выданные
  этой же сессией. Номер решения проставлен предположительно (`_ASSEMBLER §5` это разрешает): `ADR-083`
  есть следующий за максимумом `ADR-082` в `06_INDEX.md`, буфер на момент сессии пуст, веток `s/*` нет,
  конкурентов за номер не существует. **Если сборка выдаст другой номер — правки файлов правил, уже
  несущие `ADR-083` в тексте, обязаны быть пройдены тем же номером** (`§2`, сплошной поиск).

  **Контекст:** первый реальный прогон конвейера по `09_RUNBOOK.md` (2026-07-29, генерация брифа
  `SOURCE-MAP-SALES`) вскрыл семь дефектов правил, ни один из которых не является дефектом кода или
  ошибкой исполнителя. Пять найдены сессиями (генератор и сборка) независимо друг от друга, два —
  владельцем на запуске. Общий знаменатель шести из семи: правило, которое держится на памяти
  исполнителя в момент запуска, а не на механике — ровно тот класс, который `ADR-077 §1` и
  `ADR-080 §1` уже отклоняли дважды, каждый раз по факту, а не по аналогии.

  **Решение:**

  §1 **Параллелимость: булев признак СОХРАНЯЕТСЯ как ДОПУСК, пару решает механическая проверка.**
  Возражение принято по существу: «параллелится» есть свойство ПАРЫ задач, и признак на одну задачу
  его не выражает. Но из этого не следует, что признак на задачу бесполезен: он выражает НЕОБХОДИМОЕ
  условие («класс A и полный набор файлов на запись объявлен»), которое известно на момент генерации
  брифа, тогда как ДОСТАТОЧНОЕ условие (непересечение наборов) известно только на момент запуска,
  когда пара выбрана. Поэтому условие разрезается по времени, а не сводится к одному месту:
  (i) колонка «Параллель» в `07_STATE §Мандат Claude Code` и поле «Параллель» брифа остаются, но их
  смысл назначается явно — это ДОПУСК, а не разрешение; незаполненное читается как `нет` (`ADR-082 §1`
  в этой части без изменений);
  (ii) поле «Файлы на запись» получает ОБЯЗАТЕЛЬНУЮ машиночитаемую форму: заголовок ровно
  `**Файлы на запись**`, дальше маркированный список, один путь на строку, путь первым токеном в
  обратных кавычках, каталог со слэшем на конце. Основание — замер: форма реального брифа
  `briefs/SOURCE-MAP-SALES.md` извлекается, а инлайновая форма, предписанная сейчас `08` строкой 28,
  не извлекается и даёт ОТКАЗ (RC 3), не «пересечения нет»;
  (iii) вводится `tools/parallel_check.sh` (новый файл, текст в приложении патчей). Он читает поля
  «Файлы на запись» ВЫБРАННЫХ брифов, печатает извлечённые наборы целиком (`ADR-044`: совпавшие
  строки, не метка) и пересечения; пересечение = RC 1 = запускать вместе нельзя. Пересечением
  считается и вложенность (каталог-предок против файла внутри него) — проверено замером;
  (iv) прогон проверки — ОБЯЗАТЕЛЬНЫЙ шаг режима П в `09_RUNBOOK`, ДО первой команды
  `git worktree add`, а не рекомендация;
  (v) **отсутствие поля, непарсимая форма или пустой набор есть ОТКАЗ проверки, а не разрешение**
  (`ADR-021 §2`, `05` Часть I ★): единственный способ, которым такая проверка может убить сама себя, —
  тихо вернуть пустое множество и быть прочитанной как зелёный.
  **Отклонено (a): оставить булев признак плюс ручную сверку списков.** Это и есть текущее состояние;
  оно уже дало ровно один правильный результат ровно потому, что генератор-сессия случайно держала оба
  брифа в контексте. Правило, срабатывающее при удачном стечении контекста, механикой не является.
  **Отклонено (b): заменить колонку списком файлов на запись.** Список известен только после генерации
  брифа, а строка таблицы заводится раньше; и один список в двух местах (таблица и бриф) даёт дрейф,
  который пришлось бы ловить ещё одним стоп-условием — цена выше пользы.
  **Оговорка в шапке `briefs/SOURCE-MAP-SALES.md` строки 10-17 не переписывается:** она есть первая,
  ручная инстанция этой проверки и остаётся как провенанс. Следующие брифы несут только поле.

  §2 **Строка 86 `08_TASK_BRIEF_TEMPLATE.md` исправляется; правка по якорям обязана сопровождаться
  сплошным поиском понятия.** Дефект признан дефектом автора патча, не решения: `ADR-082 §2` отменил
  требование литеральных raw-URL, был применён по четырём перечисленным якорям, и файл целиком на то
  же понятие не проверялся. **Сессия нашла ВТОРОЙ инстанс того же дефекта, ранее не названный:**
  `_GENERATOR.md` строка 27 (заголовок «Прочитай из репо (raw-URL, корень репо, с подставленным SHA)»

  опечаткой и получает правило:
  **ADR, отменяющий или переопределяющий ПОНЯТИЕ (а не двигающий значение), применяется не только по

  «буфер разобран» и «каталог сломан», а именно второе состояние ведёт к исчезновению каталога из
  git (`_ASSEMBLER §2`). Скрипт различает: отсутствие каталога есть громкий отказ (RC 2), отсутствие
  `.gitkeep` при существующем каталоге печатается предупреждением.
  Скрипт знает, где он запущен: в СВЯЗАННОМ дереве чужие деревья и ветки `s/*` нормальны и

  «непустой буфер = стоп» ломало бы старт каждой сессии в своём дереве. Проверено замером в трёх
  режимах.

  **Отклонено (b): инлайновый `find` в четырёх местах** (`CLAUDE.md`, `09_RUNBOOK` дважды,
  `_ASSEMBLER` дважды). Один и тот же текст в пяти местах даёт ровно дефект §2 при первой же правке.
  **Цена названа, а не умолчана:** `bash tools/…` правилами `.claude/settings.json` не покрыт

  не требовали. Это НЕ замерено и здесь за факт не выдаётся; различитель тот же, что у

## P16 · `tools/session_status.sh` — НОВЫЙ ФАЙЛ

    # FILE: tools/session_status.sh — состояние старта сессии одной командой (ADR-083 §4)
    # Печатает ФАКТЫ положительно: счётчик плюс совпавшие строки (ADR-044).
    # Пустой вывод результатом не является: критерий — напечатанное число.
    set -uo pipefail
    root=$(git rev-parse --show-toplevel 2>/dev/null) || true
    [ -n "$root" ] || { echo "СТАТУС: не git-репозиторий" >&2; exit 2; }
    cd "$root" || exit 2
    gd=$(git rev-parse --absolute-git-dir); gc=$(cd "$(git rev-parse --git-common-dir)" && pwd)
    if [ "$gd" = "$gc" ]; then WHERE=основное; else WHERE=связанное; fi
    printf 'дерево: %s (%s)\n' "$WHERE" "$root"

    sec() { printf '\n== %s ==\n' "$1"; }

    sec "рабочее дерево"
    d=$(git status --short); n=$(printf '%s' "$d" | grep -c . || true)
    printf 'изменённых файлов: %s\n' "$n"; [ "$n" -gt 0 ] && printf '%s\n' "$d"

    sec "буфер reference/_inbox"
    if [ ! -d reference/_inbox ]; then
      echo 'КАТАЛОГА НЕТ — это отказ, а не пустой буфер'; exit 2
    fi
    b=$(find reference/_inbox -maxdepth 1 -type f ! -name .gitkeep | sort)
    nb=$(printf '%s' "$b" | grep -c . || true)
    printf 'файлов кроме .gitkeep: %s\n' "$nb"; [ "$nb" -gt 0 ] && printf '%s\n' "$b"
    [ -f reference/_inbox/.gitkeep ] || echo 'ВНИМАНИЕ: .gitkeep отсутствует (_ASSEMBLER §2)'

    sec "рабочие деревья"
    w=$(git worktree list); nw=$(printf '%s\n' "$w" | grep -c . || true)
    printf 'деревьев: %s (норма вне сессий: 1)\n' "$nw"; printf '%s\n' "$w"

    sec "ветки сессий"
    br=$(git branch --list 's/*' --format='%(refname:short)')
    nbr=$(printf '%s' "$br" | grep -c . || true)
    printf 'веток s/*: %s\n' "$nbr"; [ "$nbr" -gt 0 ] && printf '%s\n' "$br"

    sec "вердикт"
    if [ "$WHERE" = связанное ]; then
      # В дереве сессии чужие деревья и ветки нормальны и стоп-условием не являются (ADR-081 §6).
      if [ "$nb" -eq 0 ]; then echo 'ЧИСТО для сессии в своём дереве: буфер пуст'; exit 0
      else echo 'НЕ ЧИСТО: буфер непуст — сначала режим С (ADR-080 §4v)'; exit 1; fi
    fi
    if [ "$n" -eq 0 ] && [ "$nb" -eq 0 ] && [ "$nw" -eq 1 ] && [ "$nbr" -eq 0 ]; then

      exit 1
    fi

## P17 · `tools/parallel_check.sh` — НОВЫЙ ФАЙЛ

Прогнан этой сессией по РЕАЛЬНОМУ брифу `briefs/SOURCE-MAP-SALES.md` (извлечено 6 путей, строки-
продолжения с обратными кавычками не захвачены) плюс синтетическая вторая сторона. Матрица кодов
возврата: пересечение → 1; непересекающиеся → 0; каталог-предок против вложенного файла → 1;
поля нет → 3; инлайновая форма поля → 3. Временные файлы создаются в `mktemp -d` и снимаются
`trap`-ом: в рабочем дереве мусора не остаётся (проверено).

    #!/usr/bin/env bash
    # FILE: tools/parallel_check.sh — проверка пересечения наборов файлов на запись (ADR-083 §1)
    # Использование: bash tools/parallel_check.sh TASK1 TASK2 [TASK3 ...]
    # Читает поле «Файлы на запись» из briefs/<TASK>.md. Печатает извлечённые наборы
    # ЦЕЛИКОМ (ADR-044: совпавшие строки, не метка) и пересечения. RC 1 = запускать вместе нельзя.
    set -uo pipefail
    root=$(git rev-parse --show-toplevel 2>/dev/null) || true
    [ -n "$root" ] || { echo "ПРОВЕРКА: не git-репозиторий" >&2; exit 2; }
    cd "$root" || exit 2
    [ $# -ge 2 ] || { echo "ПРОВЕРКА: нужно минимум две задачи" >&2; exit 2; }
    TMP=$(mktemp -d) || exit 2
    trap 'rm -rf "$TMP"' EXIT   # временные файлы НЕ в рабочем дереве: они бы попали в git status

    extract() { # $1=TASK -> пути по одному в строке
      local f="briefs/$1.md"
      [ -f "$f" ] || { echo "ПРОВЕРКА: нет файла $f" >&2; return 3; }
      awk '
        /^\*\*Файлы на запись\*\*/ { inblock=1; found=1; next }
        inblock && /^\*\*/         { inblock=0 }
        inblock && /^- `/          { match($0,/`[^`]+`/); print substr($0,RSTART+1,RLENGTH-2) }
        END { if (!found) exit 4 }
      ' "$f"
    }

    fail=0
    declare -a NAMES
    for t in "$@"; do
      set +e; out=$(extract "$t"); rc=$?; set -e
      if [ $rc -eq 4 ]; then echo "ПРОВЕРКА: в briefs/$t.md нет поля «Файлы на запись» — это ОТКАЗ, не пустой набор" >&2; exit 3; fi
      [ $rc -eq 0 ] || exit 3
      n=$(printf '%s' "$out" | grep -c . || true)
      if [ "$n" -eq 0 ]; then echo "ПРОВЕРКА: у $t поле есть, но набор пуст — ОТКАЗ (ADR-021 §2)" >&2; exit 3; fi
      printf '== %s: %s путей ==\n%s\n\n' "$t" "$n" "$out"
      printf '%s\n' "$out" | sed 's#/$##' | sort -u > "$TMP/$t"
      NAMES+=("$t")
    done

    echo "== пересечения =="
    for ((i=0;i<${#NAMES[@]};i++)); do for ((j=i+1;j<${#NAMES[@]};j++)); do
      a=${NAMES[$i]}; b=${NAMES[$j]}
      # пересечение: равные пути ИЛИ один есть каталог-предок другого
      hit=$(awk 'NR==FNR{p[$0];next}{ for(q in p){ if($0==q || index($0,q "/")==1 || index(q,$0 "/")==1) print q" <-> "$0 } }' "$TMP/$a" "$TMP/$b" | sort -u)
      if [ -n "$hit" ]; then printf '%s x %s: ПЕРЕСЕЧЕНИЕ\n%s\n' "$a" "$b" "$hit"; fail=1
      else printf '%s x %s: пересечения нет\n' "$a" "$b"; fi
    done; done
    echo "== вердикт =="
    if [ "$fail" -eq 0 ]; then echo "ПАРАЛЛЕЛЬ ДОПУСТИМА по файлам (класс задач проверяется отдельно по 07_STATE)"; exit 0
    else echo "ПАРАЛЛЕЛЬ ЗАПРЕЩЕНА: наборы пересекаются (ADR-082 §1). Запускать по одной."; exit 1; fi
