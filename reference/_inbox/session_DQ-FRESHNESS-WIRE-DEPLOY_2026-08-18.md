- Подробности для модели: **Текстовое ревью (`try/except` есть, `CHECKS` несёт N пар) не
  ловит ошибки ПОРЯДКА определений в Python-модуле.** `main.py` исполняется сверху вниз при
  импорте; список/структура, ссылающаяся по имени на функции, обязана идти строго ПОСЛЕ их
  определений, иначе `NameError` при любом импорте — Cloud Run здесь не при чём, тот же
  результат дал бы локальный `python3 -c "import main"`. Оба прошлых ревью проверяли текст
  функций по одной, не порядок модуля целиком. Правило на будущее для любого ревью Python-CF
  патча: **факт-проверка обязана включать попытку реального импорта модуля**, не только
  построчный текстовый разбор. Полный разбор — `reference/dq_freshness_wire_deploy_2026-08-18.md`.
