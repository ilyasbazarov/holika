## NEW_DECISIONS

- ADR-0XX: Вывод ступени 3 различителя не подтверждается — пара маркетплейса не удалялась;
  остаток вопроса сжимается в пять раз; метка «удалённые» объявлена неверифицированной

  **Контекст.** Ступень 3 исполнила мандат класса B буквально и корректно: документ отгрузки за
  `2026-05-12` в МойСкладе существует, сумма `1 980 000,00` KGS сходится. Отсюда сессия вывела
  подтверждение гипотезы (b) — удаление было дефектом выгрузки. Посылку «эта пара была удалена»
  сессия не проверяла: мандат её не требовал, а репозиторий подавал её как установленный факт.

  **Решение.**
  **§1 Посылка ложна, вывод не принимается.** Обе строки пары присутствуют в
  `core.fact_sales_profit` сейчас, `_loaded_at = 2026-07-19 01:08:45`, загруженных после
  `2026-08-11` среди `29` — ноль. Обе ветки промоута проставляют `_loaded_at = CURRENT_TIMESTAMP()`
  и на вставке, и на обновлении, поэтому траектория «удалено `2026-08-12`, восстановлено позже с
  сохранением июльской отметки» задеплоенным кодом недостижима. Измеренное ступенью 3 есть
  совпадение ядра с источником по этой паре — факт положительный, но о другом предмете.
  **§2 Остаток вопроса переопределён численно:** `27` строк / `427 220,42` KGS вместо `29` /
  `2 407 220,42`. Три четверти денежной величины, ради которых выдавался мандат класса B, из
  вопроса выбывают. Остаток — `0,45 %` майской выручки ядра.
  **§3 Метка «удалённые» у `deleted_29.csv` объявляется неверифицированной.** Файл собран как
  разность двух множеств (строки таблицы минус архив выгрузки), то есть содержит КАНДИДАТОВ на
  удаление веткой `DELETE`. Для `2` из `29` удаление доказанно не состоялось; для остальных `27`
  ни один замер не показал, были ли они в таблице когда-либо.
  **§4 Назван повторяющийся дефект метода расследования, а не сессии.** Третий подряд критерий
  этого расследования не выдержал проверки: «документ есть, позиции нет ⇒ дефект» (снят
  `ADR-165`), обрезка позиций постраничным пределом (опровергнута замером `2026-08-18`), метка
  «удалённые» (опровергнута здесь). Общее — величина, полученная вычитанием двух множеств,
  объявлялась СОБЫТИЕМ без независимого подтверждения, что событие произошло. Правило-кандидат:
  разность множеств именуется разностью, а не событием, пока событие не подтверждено отдельным
  признаком (для этой таблицы такой признак есть — `_loaded_at`).
  **§5 Форма закрытия остатка — два шага, дешёвый первым** (`reference/delete_stage3_adj_2026-08-18.md §4`):
  шаг 1 класс A по резервной копии `core.fact_sales_profit_byvariant_backup`, живых вызовов не
  требует и может закрыть вопрос целиком; шаг 2 класс B (до `24` read-only `GET` по `12` парам
  одним пакетом) — только при положительном исходе шага 1. Выдача мандатов по одной паре
  отменяется как дороже предмета.
