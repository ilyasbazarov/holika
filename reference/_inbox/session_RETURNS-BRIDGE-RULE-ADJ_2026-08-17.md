## NEW_DECISIONS  (→ append в 06_DECISIONS_LOG.md как ADR; "нет" если нет)
- ADR-0XX: `RETURNS-BRIDGE-RULE-ADJ` — правило-мост пары «Возвраты покупателей» достроено; объект
  паритета сужается на возвраты с основанием (легитимное отступление); критерий сходимости —
  инвариант разложения `Δ = P − O + ε`; непогруженный документ UMAI WB относится к свободному
  остатку разложения (компонент `O`), а не лежит вне объекта паритета
  Контекст: `ADR-181 §4` завела задачу как остаток (i) строки `PARITY-CLIENT-JULY-RECHECK` —
  правило-мост пары не было записано; май-2026 (`ADR-098`, `570,00=570,00`) не проверялся на
  данных с возвратами без основания, июль — первый такой месяц и обнажил это (замечание клиента,
  `parity_client_july_recheck_2026-08-13.md`).
  Решение: §1 два сверяемых числа с адресом — `A` = `report/profit/bycounterparty.returnSum`
  (уровень (i), контрольный путь (ii) — оба типа entity), `B` = `SUM(core.fact_returns.sum_kgs)`
  за период, ОГРАНИЧЕННАЯ документами с основанием. §2 оракул структурно считает только возвраты
  с основанием (подтверждено точным совпадением, `62 709,00=62 709,00`); возвраты без основания
  (`271 476,66` KGS, три документа «Неман Фарм», июль) — легитимное отступление, закрывающее
  решение — настоящий ADR (аналог периметровых исключений расходов `ADR-002`/`ADR-005 п.1`).
  Признак «основание» реализован дефектным полем `has_basis` (`ADR-098 §5`, `Q-101` DEFER) —
  правило моста полагается на установленный факт семантики оракула, не на само поле; будущие
  месяцы верифицируют периметр сверкой суммы. §3 критерий сходимости — инвариант разложения
  (форма `ADR-157 §1`), не порог: `Δ = P − O + ε`, `P` — сумма без основания (§2), `O` — сирота
  эталона (документ есть у оракула, отсутствует в `core.fact_returns`), `ε` — остаток `< 1 KGS`.
  Пара сошедшаяся, пока `Δ` раскладывается без свободного остатка; переоткрывается только при
  появлении неотнесённой суммы. §4 замер июля закрывает инвариант точно: `Δ=269 995,53`,
  `P=271 476,66`, `O=1 481,13`, `P−O=269 995,53=Δ`, `ε=0,00`. Май-2026 — частный случай той же
  формулы (`P=0`, `O=0`, `Δ=0,00`). §5 непогруженный документ UMAI WB (`O`) относится к
  СВОБОДНОМУ ОСТАТКУ разложения, а не лежит вне правила: это не решённое периметровое исключение
  (в отличие от `P`), а незакрытый дефект полноты ингеста (`RETURNS-INGEST-COMPLETENESS`,
  `K1`/`K2`/`K3` опровергнуты, `K4` подтверждён методом исключения, точный тип не идентифицирован);
  решение владельца не расследовать тип дальше (`ADR-181 §2`) останавливает расследование
  механизма, не исключает сумму из объекта паритета — компонент входит в разложение как
  ИМЕНОВАННЫЙ (класс `K4`) остаток, поштучная идентификация документа критерием не требуется.
  §6 вердикт: пара «Возвраты покупателей» остаётся СОШЕДШЕЙСЯ (статус `ADR-114 §2` не
  переоткрывается), счётчик реестра не двигается; рост `Δ` с `0,00` (май) до `269 995,53` (июль)
  не есть регресс — прецедент формы `ADR-157 §2` («сошлась» значит «объяснена»). Разрез возвратов
  по контрагенту остаётся вне финишной черты (`ADR-114 §3`, не пересматривается).
