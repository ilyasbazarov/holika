## 4. Находка первого прогона: `34` платежа с неизвестной валютой

```
WARNING: cashout <id>: currency=580251fe-2e47-11ef-0a80-16e40062d265 (iso=None) без rate.value
WARNING: 34 платежей с валютой ≠ KGS без rate.value (currency_mismatch, INGEST-CURRENCY-ASSERT)
```

**Что установлено фактом.** Все предупреждения несут ОДИН и тот же идентификатор валюты, и у всех
`iso=None` — то есть этого идентификатора НЕТ в справочнике `entity/currency`, из которого строится
карта. Карта при этом построена исправно: будь она пустой, сработало бы на каждой строке из `6750`,
а сработало на `34`.

**Чем это НЕ является.** Не ложным срабатыванием из-за недоступности справочника — тогда печаталось
бы «детекция НЕ выполнялась». Не дефектом патча — детекция сработала ровно по правилу `ADR-101 §5`:
доказать, что валюта сомовая, нечем, курс не проставлен.

**Масштаб — из ядра, чтением.** Из `22` идентификаторов, попавших в хвост журнала, `21` найден в
`core.fact_payments`: даты `2024-06-18`…`2024-09-17`, сумма `378 517,09` сом. Все — **2024 год**,
то есть вне окна паритета (`с 2026-05-01`, `ADR-069`). Суммы этих строк посчитаны по запасной ветке
`or 1.0` (`ADR-029 §1`), значит верны тогда и только тогда, когда эта валюта — сом.

**Форма закрытия — реестр известных ограничений, не задача** (`ADR-156 §2/§5`: discovery-петля на
фазе передачи выключена, новая находка идёт текстом). Запись внесена в
`reference/handover_limitations.md`. Установить, что это за валюта, стоит одного чтения справочника
МойСклада — это класс B, мандат не выдан и этой сессией не запрашивается.
