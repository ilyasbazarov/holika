# FILE: tools/README.md — провенанс скриптов комплекта

Четыре скрипта и хук перенесены из проекта holika **дословно**, коммит `5b2d8df` (2026-08-18).
Доменной логики в них нет: они оперируют только именами файлов метода.

| Файл | Что делает | Ключевое свойство |
|---|---|---|
| `session_status.sh` | состояние старта одной командой | печатает счётчики; различает основное и связанное дерево; RC 1 при «не чисто» |
| `inbox_manifest.sh` | инвентарь буфера session-блоков | превращает утверждение о буфере в напечатанный факт ДО первой правки |
| `inbox_manifest_selftest.sh` | самотест инвентаря | негативный набор вне рабочего дерева |
| `parallel_check.sh` | пересечение наборов файлов на запись у пары задач | печатает наборы целиком; отсутствие поля = ОТКАЗ, не разрешение |
| `hooks/pre-commit` | шесть механических инвариантов коммита | вердикт печатает совпавшие строки, а не метку |
| `hooks/selftest.sh` | самотест КАЖДОЙ проверки хука по отдельности | принимается только «провалено 0» |

## Установка

```
ln -s ../../tools/hooks/pre-commit .git/hooks/pre-commit
bash tools/hooks/selftest.sh      # ожидание: провалено 0
bash tools/session_status.sh      # ожидание: «чисто»
```

**Самотест обязан быть зелёным до первого коммита, а не после.** Сломанная проверка хуже
отсутствующей, потому что её отказ тихий.

## Про ссылки вида `ADR-NNN` в комментариях

Они указывают на решения журнала holika и объясняют, **почему** конкретная строка написана
именно так. В новом проекте номера будут свои, поэтому ссылки формально повиснут.

**Ссылки не вычищены сознательно.** Комментарий «какой отказ ловит эта строка» ценнее, чем
чистота нумерации, а сплошная замена через `sed` — ровно тот класс правки, который метод
требует делать со сплошным поиском и разбором каждого совпадения поимённо.

Правильный порядок: перенести как есть → убедиться, что самотест зелёный → отдельной задачей
заменить ссылки на собственные номера, вынеся вердикт по каждому совпадению.

  «пункт `[сейчас]` вне полномочий сборки» даст находки на легитимных пунктах.
