## 2. Форма вопроса архитектору (нога 4)

Файл `reference/review_request_dq_checks_order_2026-08-18.md` несёт ровно это и ничего сверх:

| Раздел | Содержание |
|---|---|
| Предмет | шаг (2) остатка `ADR-186 §6` — повторное ревью с факт-проверкой исполнением |
| База | `SHA` основного дерева после ноги 3 |
| Что изменено | адрес файла, номера строк «было/стало», полный `git diff` |
| Факт-проверка | команда импорта дословно, версия интерпретатора, вывод, `len(CHECKS)` |
| Четыре пункта приёмки | по каждому — факт, а не «выполнено» |
| Адреса логов | пути в `reference/_scratch_DQ-FRESHNESS-WIRE-CHECKS-ORDER_2026-08-18/` |
| Что НЕ делалось | перечислить явно |

В чат уходят только четыре строки: адрес файла, `SHA`, сводный вердикт, просьба. Коды и номера
строк в сообщении владельцу не разворачиваются (`ADR-093 §2`).

**Архитектор отвечает двумя вещами:** (i) вердикт «готов / не готов» с основанием; (ii) при
«готов» — текст мандата класса B: объект, предусловия, приёмка, откат. Владелец несёт ответ
обратно в чат цепочки одним куском.
