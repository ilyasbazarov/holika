Даты хранятся Excel-серийным числом (`row_types[0] == 3`, `XL_CELL_DATE`... фактически numeric),
переведены через `xlrd.xldate.xldate_as_datetime(serial, wb.datemode)`. Три последние строки листа
(156–158) — текстовые сноски (`row_types[0] == 1`), корректно отфильтрованы по типу ячейки, не по
пропуску строк на глаз.

**Скрипт чтения (Python 3, `xlrd==2.0.2`):**

```python
import xlrd
import datetime

wb = xlrd.open_workbook('reference/_scratch_fx_may_window_2026-07-28/nbkr_dailyrus_raw.xls')
sh = wb.sheet_by_name('2026')

start = datetime.date(2026, 5, 11)
end = datetime.date(2026, 6, 2)

rows = []
for r in range(1, sh.nrows):
    types = sh.row_types(r)
    if types[0] != 3:
        continue
    vals = sh.row_values(r)
    serial = vals[0]
    d = xlrd.xldate.xldate_as_datetime(serial, wb.datemode).date()
    if start <= d <= end:
        rows.append((d.isoformat(), vals[1]))

rows.sort()
for d, usd in rows:
    print(d, usd)
print("count:", len(rows))
```

## Шаг 4 — формулировка следствия (без квалификации)

Совпадение по всем 23 суткам означало бы продолжение гипотезы **(B)** (таблица честно отражает
малоподвижный источник) на весь отрезок. Наблюдаемый результат — расхождение на 22 сутках из 23,
все одного знака и одной величины (`−0.0295` KGS = таблица ниже источника), с единственным
совпадением точно на границе отрезка (2026-05-11, первая дата, непроверенная ранее). Это означает
**(A)** на датах `2026-05-12…2026-06-02` в терминах брифа: находка соответствует гипотезе «слой
курсов зафиксировал старое значение и не подхватил переход источника», требует фикс-форварда в
слой курсов, а не в марты (`ADR-062 §7`), если находка подтвердится квалификацией.
