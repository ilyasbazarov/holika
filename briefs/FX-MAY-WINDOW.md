курсов» для окна, если копирование предыдущего дня исключено. Записать в артефакт ДО результатов D1–D3.

**Шаг D1 — прочитать `nbkr_dailyrus_raw.xls`.**
Сначала локализовать, не угадывая путь: `gcloud storage ls -r 'gs://msklad-raw-msklad-bi-prod/**'` (или
`gsutil ls -r`), отфильтровать по имени файла, зафиксировать полный путь, размер и `Creation`/`Update`.
Скачать в рабочую папку. Прочитать содержимое: попробовать по очереди `python3` с `pandas`/`openpyxl`/`xlrd`,
затем `libreoffice --headless --convert-to csv`. **Если ни один ридер недоступен — остановись и скажи

изменение среды, спроси владельца, сам не ставь.
Что искать: есть ли в файле ежедневные курсы НБКР за `2026-05-01…2026-06-02`. Если есть — построчная сверка
«что в файле» против `core.dim_fx_rates` за те же даты, дословно, включая расхождения.

**Шаг D2 — история заданий BigQuery по записям в `core.dim_fx_rates` за окно.**
Два независимых захода:
(а) `bq --project_id=msklad-bi-prod ls -j --all_users --min_creation_time=<ms> --max_creation_time=<ms> -n 1000 --format=prettyjson`
по окну плюс несколько дней с каждой стороны;
(б) запрос к `` `region-asia-east1`.INFORMATION_SCHEMA.JOBS_BY_PROJECT `` с фильтром по
`destination_table.dataset_id = 'core'` и `table_id = 'dim_fx_rates'` за окно — вернуть `job_id`, `user_email`,
`creation_time`, `statement_type`, `query`.
Различает: загрузчик писал одно значение изо дня в день **против** разовая вставка литеральной константы;
плюс даёт личность писавшего. Горизонт хранения метаданных заданий в репо не зафиксирован — если окно за
горизонтом, это гэп наблюдения, а не «заданий не было». Ошибка по региону — факт, записать её и не
перебирать регионы наугад (документирован `asia-east1`).

**Шаг D3 — опознать до-миграционный загрузчик курсов.**
Сначала имя, потом логи. Read-only инвентари: `gcloud functions list`, `gcloud run services list`,

разброс с зафиксированным `[87.4205; 87.45]` = 0,0295 KGS = 0,0337 %. Разброс шире ⇒ оценка 39,49 USD

выдержки, вывод либо явный гэп с причиной; результат шага 4; строка «прод не тронут: ни одной команды записи».
