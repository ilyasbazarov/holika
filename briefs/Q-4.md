## Шаги
1. **UTC-якорь + личность** (`05_CONVENTIONS` Часть II п.3/4): `date -u` и `gcloud auth list` — первой
   командой скрипта.
2. Один скрипт-файл (`ADR-055 §1`, доставка через файл, редирект в лог):
   ```bash
   bq query --use_legacy_sql=false --format=prettyjson '
   SELECT table_schema, table_name, column_name, data_type, is_nullable, ordinal_position
   FROM `msklad-bi-prod`.`region-asia-east1`.INFORMATION_SCHEMA.COLUMNS
   WHERE table_schema IN ("core", "marts", "audit", "stg_msklad")
   ORDER BY table_schema, table_name, ordinal_position

   ```
   Read-only, ничего не пишет — класс A без оговорок.
3. `date -u` и `gcloud auth list` — последней командой того же скрипта (детектируемая деградация

   `table_schema.table_name`, плюс шапка с UTC-якорями начала/конца и SHA сессии.
5. Диф с уже задокументированным в `02_ERP_CONTRACTS.md §схемы core/§схемы dim`: для каждой расходящейся
