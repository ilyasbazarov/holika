**Шаг 1 — discovery `.git`, read-only, один скрипт.** Исполняется либо этой сессией (если доступ подтверждён), либо владельцем в Cloud Shell по стандартной доставке (`ADR-055 §1`: heredoc в файл, `bash script.sh > run.log 2>&1; cat run.log`). `date -u` первой и последней командой (`ADR-055 §3`).

```bash
#!/usr/bin/env bash
set -euo pipefail

date -u

TARGET="/home/ilyasbazarov4/cf-finance"

echo "=== существование каталога ==="
ls -la "$TARGET" 2>&1 || echo "КАТАЛОГ НЕ НАЙДЕН"

echo "=== существование .git ==="
if [ -d "$TARGET/.git" ]; then
  echo ".git ЕСТЬ"
  cd "$TARGET"

  echo "--- git status ---"
  git status 2>&1

  echo "--- git log (полная история, по одной строке на коммит) ---"
  git log --oneline --all 2>&1 || echo "git log ПУСТ ИЛИ УПАЛ"

  echo "--- git log -1 (последний коммит целиком) ---"
  git log -1 2>&1

  echo "--- git remote -v ---"
  git remote -v 2>&1 || echo "REMOTE НЕ ЗАДАН"

  echo "--- git branch -a ---"
  git branch -a 2>&1

  echo "--- diff .git-состояния HEAD против прод-снапшота main.py (если файл там есть) ---"
  if [ -f "$TARGET/main.py" ]; then
    sha256sum "$TARGET/main.py" 2>&1
  else
    echo "main.py НЕ НАЙДЕН НА ВЕРХНЕМ УРОВНЕ КАТАЛОГА"
  fi
else
  echo ".git ОТСУТСТВУЕТ"
fi

echo "=== содержимое каталога верхнего уровня (на случай нестандартной структуры) ==="
find "$TARGET" -maxdepth 2 2>&1 || true

date -u
```

> **Не примирять пустой/оборванный вывод** (`05` Часть I, `ADR-021 §2`): `КАТАЛОГ НЕ НАЙДЕН` — факт, а обрыв посреди `git log` (незакрытая строка, признаки наложения) — Untrusted, чистый перезапуск.

**Шаг 2 — разбор лога, без интерпретации сверх факта.** Зафиксировать дословно: есть ли `.git`; если есть — сколько коммитов, диапазон дат первого/последнего, есть ли remote и куда он указывает, совпадает ли sha256 `main.py` в `.git`-дереве (если он там лежит на HEAD) с sha256 задеплоенного `main.py` из `11_INFRA_FACTS.md §CF` (`0cb4f6698a61cee96c90f9a14973ada38f5123418b54ff901f24ea2026ddab59`). Совпадение/несовпадение — факт для развилки следующего шага, решение по нему этой сессией НЕ принимается (`ADR-017 §5`, owner-gated).
