## Шаги

**Шаг 1 (read-only). Свежий съём исходников обеих функций.** Один скрипт на шаг (`ADR-077 §6`),
доставка через файл с логом (`ADR-055 §1`), якоря `date -u` и `gcloud auth list` первой И последней
командой (`ADR-063 §4`).

Известное ограничение: прямой `gcloud functions describe cf-facts` ранее возвращал `403`; рабочий
обходной путь — `gcloud run services describe`. Обходной путь допустим, но **способ съёма обязан
быть назван в `MANIFEST.md` дословно**, а не подразумеваться.

Целевой результат шага — для каждой из `cf-facts`, `cf-dq`: имя текущей ревизии, её `createTime`,
URL архива исходников (`generation`), скачанный архив, распакованные файлы, `sha256` каждого файла.

**Шаг 2. Сверка «на диске = задеплоено».** Для `cf-dq`: сравнить sha256 свежего съёма с
`reference/code/cf-dq/MANIFEST.md`. Совпало → снапшот подтверждён, файлы не переписывать. Не
совпало → это находка, а не повод молча перезаписать: назвать расхождение в артефакте.

Для `cf-facts`: сверять не с чем (замера нет по построению) — свежий съём СТАНОВИТСЯ базой, и это
фиксируется в `MANIFEST.md` явной строкой «первый замер равенства, предыдущего не было».

**Шаг 3. Гигиена архива (`ADR-040`).** Перечислить содержимое каждого архива полностью. Мусор
(`*.bak`, `__pycache__/`, разовые patch-скрипты) в seed НЕ включается и покрывается `.gitignore` —
ровно как сделано для `cf-finance` (`reference/code_repo_standup_d2_2026-08-01.md`). Каждый
исключённый файл назвать поимённо в артефакте.

Отдельно: `patch_dq.py` внутри архива `cf-dq` — не мусор, а провенанс T-1-фикса
(`reference/dq_source_capture_2026-08-02.md` §6). Решение о его включении в seed принять явно и
обосновать в артефакте.

**Шаг 4. Локальный клон и коммит.** Клонировать `holika-prod` в рабочий каталог сессии (НЕ в репо
`holika`), разложить исходники по каталогам одного уровня — предлагаемая форма:
`cf-finance/`, `cf-facts/`, `cf-dq/`. Существующие три файла `cf-finance` в корне репозитория
переносятся в `cf-finance/` тем же коммитом либо остаются в корне — **выбор формы объявить в
артефакте с обоснованием, не по умолчанию.**

Сообщение коммита — по образцу существующего:
`Seed cf-facts from deployed revision <REV> (generation <GEN>); seed cf-dq from deployed revision <REV> (generation <GEN>)`

Коммит локальный. **`git push` не исполнять** — класс B, владелец.

**Шаг 5. Артефакт.** `reference/code_repo_seed_rest_2026-08-03.md`: способ съёма каждой функции,
имена ревизий и generation, полный список файлов архива, что исключено и почему, sha256 таблицей,
выбранная форма раскладки с обоснованием, SHA локального коммита, точная команда `push` для
владельца.
