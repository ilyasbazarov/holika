## Шаги

Один скрипт на шаг, лог в файл. Живых операций с секретами в этой задаче минимум — если Шаг 1 не
требует сетевого вызова (ревизия не дрейфовала), `date -u`/`gcloud auth list` не нужны вообще; если
требует — по правилу `ADR-055/063` (первой И последней командой).

1. **Переподтвердить свежесть `reference/code/cf-dq/`.** `gcloud functions describe cf-dq --gen2
   --region=asia-east1 --project=msklad-bi-prod` (read-only) → сравнить `serviceConfig.revision` с
   зафиксированной в `MANIFEST.md` (`cf-dq-00007-hot`).
   - Ревизия НЕ изменилась → в новом артефакте процитировать дословно `main.py:100-104`
     (`check_currency_normalization`) как факт, закрывающий формулировку шага 1 из `07_GAPS.md:67`
     буквально («напечатать фактический текст проверки») — переиспользуя, не пересобирая уже верный
     снапшот `DQ-SOURCE-CAPTURE`. Явно назвать в артефакте расхождение между текстом GAP-строки
     (числит шаг 1 невыполненным) и фактом (`07_ARCHIVE.md` строка `DQ-SOURCE-CAPTURE`, `Q-6` CLOSED).
   - Ревизия ИЗМЕНИЛАСЬ → снять исходник заново тем же приёмом, что `DQ-SOURCE-CAPTURE` (`gcloud
     functions describe` + `gsutil cp` задеплоенного архива), обновить `reference/code/cf-dq/` и
     `MANIFEST.md` (новые sha256, дата снятия UTC).

2. **Перепроверить сплошной поиск точек конвертации** (раздел «Входы» выше) командой из того же
   раздела, напечатать совпавшие строки с номерами (`★` расширение `ADR-044`) — не доверять списку,
   данному брифом, как факту без повторной проверки.

3. **Построить карту валюта-UUID → `isoCode`.** Для каждого CF, где будет вставлена детекция
   (`cf-facts`, `cf-finance`), добавить функцию по образцу уже существующих `_fetch_sales_channel_map`/
   `_fetch_project_map` в `fetch_demands.py`: один вызов `entity/currency` (пагинированный,
   `paginate_entity`), строит `{uuid: isoCode}` из `parse_href(row["meta"]["href"])` → `row["isoCode"]`.
   **НЕ** использовать `expand=rate.currency` — подтверждённая ловушка `Q-49`/`02_ERP_CONTRACTS.md:425`
   (см. «Context-to-load»). Функция вызывается один раз за прогон, как остальные lookup-карты.

4. **Вставить детекцию в каждую точку конвертации** (кроме `fetch_purchases.py`, если разбор шага 2
   покажет, что там уже нет `or 1.0` — тогда описать её текущее поведение отдельно, не молчать; кроме
   `cf-loss-commission`, вне scope):
   - Для позиции/строки: `currency_id = parse_href(rate.get("currency", {}).get("meta", {}).get("href", ""))`,
     `iso_code = currency_map.get(currency_id)`, `has_rate = rate.get("value") is not None`.
   - `currency_ok = (iso_code == "KGS") or has_rate`.
   - При `not currency_ok` — `log.warning` с id документа/позиции и `iso_code`, инкремент локального
     счётчика (по образцу уже существующего `skipped_demands`/`excluded` в `fetch_demands.py`),
     печать итогового счётчика в конце функции (`log.warning("N позиций с валютой ≠ KGS без rate.value", n)`).
   - **Арифметика `revenue_kgs`/`sum_kgs`/`price_kgs` НЕ меняется** — `currency_rate = ... or 1.0`
     остаётся как есть, детекция добавляется РЯДОМ, не заменяет существующую ветку. Это разграничивает
     «обнаружить» (эта задача) от «исправить» (Шаг 4 ниже — только называется, не исполняется).

5. **Зафиксировать находку ADR-029 §1.** Действующий паттерн `... or 1.0` во всех проверенных точках —
   прямое нарушение уже принятого правила («fallback-ветка ОБЯЗАНА падать исключением, если курс не
   прочитан; 1.0 запрещён», `reference/code/cf-finance/invoices.py` шапка модуля, цитирующая
   `ADR-029 §1`). В проекте уже есть задеплоенный образец правильной формы —
   `invoices.py::rate_and_currency`/`_fetch_current_rate`. Написать в артефакте одним абзацем:
   замена детекции на исправление (живой fetch текущего курса вместо `1.0`) меняет значения
   `revenue_kgs`/`sum_kgs` задним числом при повторной загрузке — больший blast radius, отдельное
   решение/задача, НЕ исполняется этой сессией.

6. **Offline-тест без секрета и без живого `GET`** — по образцу
   `reference/_scratch_INVOICES-LOADER-BUILD_2026-08-02/checks/currency_test.py`: синтетические

7. Собрать `reference/ingest_currency_assert_2026-08-03.md`: открывающий блок (цитата `07_GAPS.md:67`
